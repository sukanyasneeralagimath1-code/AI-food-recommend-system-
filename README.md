# AI-food-recommend-system-# 🤖 AI Food Recommendation System

A simple and attractive web application that recommends food based on the user's mood.

## 🌟 Features

- 😊 Mood-based food recommendations
- 🍕 Different food suggestions
- 🎉 Confetti animation
- 🔊 Text-to-speech food recommendation
- ⏳ Loading animation
- 📜 Recommendation history
- 🔄 Try Another Food option
- 📱 Responsive design
- ✨ Modern glassmorphism UI
- 🌈 Animated background

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js

## 🎭 Available Moods

The application provides food recommendations for:

- Happy
- Sad
- Tired
- Romantic
- Sick
- Party
- Gym
